One-time setup

To share this calendar so others can edit it, you'll connect it to a free GitHub Gist. Takes about 3 minutes.

1
Go to github.com/settings/tokens and create a Personal Access Token (classic). Under "Select scopes," check only gist. Copy the token (starts with ghp_).
2
Paste the token below and click Connect. The calendar will create a private Gist to store events and give you a shareable link.
3
Send the link to anyone you want to collaborate with. They'll need their own token (with gist scope) to edit — sharing yours is not recommended.
